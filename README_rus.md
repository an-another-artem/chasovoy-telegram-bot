# Часовой Telegram-бот

**[English README.md](README.md)**

Часовой Telegram-бот — это бот для оповещения о времени в Telegram. Когда его добавляют в группу или канал в качестве администратора, он каждый час отправляет сообщение с текущим временем — например, «Сейчас 2 часа дня в столице» — используя различные шаблоны сообщений.

## Возможности

- **Автоматические почасовые оповещения:** Бот отправляет текущее время каждый час во все группы и каналы, где он является администратором.
- **Вариативные сообщения:** Используется множество вариантов шаблонов сообщений для большего разнообразия и вовлечённости.
- **Простое развертывание:** Используется Ansible для удобной настройки сервера и деплоя.

## Установка и развертывание

### Необходимые компоненты

- **Python-зависимости:** `aiogram`, `apscheduler`, `pytz`
- **Ansible** установленный на вашей локальной машине
- **Сервер** (VPS или другой), на котором будет работать бот
- **API-токен Telegram-бота** (получается у @BotFather)

### Шаги

1. **Клонируйте репозиторий**
    ```bash
    git clone https://github.com/yet-another-artem/chasovoy-telegram-bot.git
    cd chasovoy-telegram-bot
    git checkout develop
    ```

2. **Установите Ansible**
    ```bash
    pip install ansible
    ```

3. **Настройте инвентарь**
    - Добавьте информацию о вашем сервере в файл `./ansible/ansible_inventory.yml`.

4. **Задайте токен Telegram-бота**
    - Получите токен у вашего бота через [@BotFather](https://core.telegram.org/bots#botfather).
    - Замените зашифрованный токен в `./ansible/roles/ansible_deploy_tg_bot_role/vars/main.yml` на ваш реальный API-токен.

5. **Запустите плейбук Ansible**
    ```bash
    ansible-playbook -i ./ansible/ansible_inventory.yml ./ansible/deploy.yml
    ```

## Конфигурация

- **ansible/ansible_inventory.yml:** Здесь указываются ваши сервер(а) для деплоя.
- **ansible/roles/ansible_deploy_tg_bot_role/vars/main.yml:** Здесь хранится API-токен Telegram-бота. **Никогда не коммитьте свой реальный токен в репозиторий!**

## Использование

- Добавьте бота в группу или канал Telegram в качестве администратора.
- Бот будет автоматически публиковать текущее время каждый час.
- Форматы сообщений варьируются для большего вовлечения участников.
